# MacroView

MacroView is a React Native app that allows the user to scan food ingredient with the camera to search for nutritional information. Ingredient are fetched from Spoonacular API and can be stored locally with SQLite.

Key technologies:
- React Native + TypeScript
- React Tab/Stack Navigation
- SQLite — local persistent storage for saved ingredients.
- Spoonacular API — external ingredient lookup.
- React Native Vision Camera — camera component used for object detection 
- TensorFlow Lite —  object recognition
